# Claude project entry point

Before working in this repository, read and follow `AGENTS.md`.

Mandatory: updates must preserve users' progress. Major changes require a tested, recoverable migration from previously released formats; never reset saves or require users to recreate their progress. See the compatibility and migration requirements in `AGENTS.md`.

For frontend or design work, also read `public/AGENTS.md`. It contains the redesign scope, required user flows, compatibility rules and visual verification checklist.

Use those files as the shared source of project instructions rather than maintaining a separate Claude-specific copy. Read `docs/DEVELOPMENT.md` for running and deploying the application (`docs/SELF-HOSTING.md` for the Docker edition's settings; `README.md` and `docs/USER-GUIDE.md` describe what users see). Preserve existing profiles/progress, the Docker edition and the browser-only GitHub Pages edition throughout a redesign.
