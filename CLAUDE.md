# Claude project entry point

Before working in this repository, read and follow `AGENTS.md`.

For frontend or design work, also read `public/AGENTS.md`. It contains the redesign scope, required user flows, compatibility rules and visual verification checklist.

Use those files as the shared source of project instructions rather than maintaining a separate Claude-specific copy. Read `README.md` for running and deploying the application. Preserve existing profiles/progress, the Docker edition and the browser-only GitHub Pages edition throughout a redesign.
